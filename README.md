### 📌 Featured Projects

#### 🤖 AgentForge — Multi-Agent AI Platform
> A full-stack platform where multiple AI agents collaborate on research, coding, document analysis and content generation.
- Backend in **Node.js / Express / MongoDB** with **JWT auth** and session management.
- Agent orchestration via **LangChain & LangGraph**, with **RAG over Qdrant** for context-aware retrieval.
- **Redis** for caching and conversation memory, plus file uploads, document processing and streaming responses.

`MERN` · `LangChain` · `LangGraph` · `Qdrant` · `Redis`

#### 🎓 AcadPulse — Student ERP & Performance Analytics
> A role-based ERP portal for students, teachers, parents and admins to manage academic records and track performance.
- **Student profiling** that aggregates attendance and marks to flag at-risk students and assess placement readiness.
- **AI-powered insights module** that reads performance trends to generate recommendations and early-warning alerts.

`React` · `Node.js` · `Express.js` · `MongoDB`
